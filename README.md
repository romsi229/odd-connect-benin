# 🌍 ODD Connect Bénin — Guide de déploiement

## Ce que contient ce dossier

Ton application complète ODD Connect Bénin avec :
- 9 pages : Accueil, Dashboard, Plaidoyer, Veille citoyenne, Cartographie, Forum, Bibliothèque, Calendrier, Profil
- Graphiques interactifs, carte du Bénin, données ODD réelles

---

## ÉTAPE 1 — Créer un compte GitHub (5 minutes)

1. Va sur **https://github.com**
2. Clique sur **"Sign up"**
3. Entre ton email, un mot de passe, un nom d'utilisateur (ex: `oddconnect-benin`)
4. Vérifie ton email et connecte-toi

---

## ÉTAPE 2 — Mettre le code sur GitHub (5 minutes)

1. Sur GitHub, clique sur le bouton vert **"New"** (haut à gauche)
2. Nomme le dépôt : `odd-connect-benin`
3. Laisse tout par défaut, clique **"Create repository"**
4. Sur la page suivante, clique sur **"uploading an existing file"**
5. **Glisse-dépose TOUS les fichiers de ce dossier** dans la zone
6. Clique **"Commit changes"**

---

## ÉTAPE 3 — Déployer sur Vercel (3 minutes)

1. Va sur **https://vercel.com**
2. Clique **"Sign up"** → choisis **"Continue with GitHub"**
3. Autorise Vercel à accéder à GitHub
4. Clique **"Add New Project"**
5. Sélectionne ton dépôt **odd-connect-benin**
6. Vercel détecte automatiquement Vite — clique juste **"Deploy"**
7. Attends 1 minute ✨

**Ton site est en ligne sur une adresse du type :**
`https://odd-connect-benin.vercel.app`
